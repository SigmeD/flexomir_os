## Переписка и документы — Owner 12–13.11

Основание: прямые правки Owner и последнее уточнение «Можно CRUD, до момента пока не прочитает пользователь». [Реализация и доказательства](COMM_DOCS_2026-11-12.md). PR #46 MERGED по прямому поручению «сделай merge в main/origin»; повторное разрешение этой поставке не требуется.

- Save и More видны сразу. Save disabled без собственных корректных несохранённых изменений, включая первое Send и повторное открытие. Save сохраняет локальные изменения и возвращает в свой список поддержки.
- Общие чаты допускают следующие сообщения. Собственное непрочитанное можно редактировать/удалять через общее Glass-меню. После прочтения другим участником остаётся Copy текста.
- При входе заказа в Work прежние сообщения фиксируются; новые Work сообщения допускают CRUD до прочтения. Возврат статуса и closed/cancelled workflows этим не утверждены.
- Удаление тикета очищает только его локальный контекст. Duplicate disabled: состав копии OPEN, первое сообщение/вложение или вся история — решение Owner.
- Бланк удаляется по local file ID корзиной справа от скачивания. Добавление файла — в заголовке; большой загрузчик только при отсутствии файлов. Реальные server delete/ACL/версии не утверждены локальным действием.
- Короткое нажатие переключает mic/video, удержание запускает запись, отпускание готовит её к отдельной отправке. D03/D08 уточнены для этого UI; D09 и production-интеграция открыты.
