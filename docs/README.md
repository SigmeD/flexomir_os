## Нужны ли Playwright-конфиги в корне

Да. Это исполняемые настройки проверок, а не отчёты. Всего 23: они выбирают тесты, браузеры, размеры, touch/production-режим и пути артефактов. Большинство прямо используются GitHub Actions; config/profile/fe11 также служат базами наследования. Удаление или перенос требует отдельного изменения CI, импортов и команд запуска. При этой ревизии конфиги сохранены.

| Конфиги `playwright.*.config.ts` | Назначение |
| --- | --- |
| Основной `playwright.config.ts` | Общий набор, Chromium 1440/390; материал исключён |
| profile | Chromium/Firefox/WebKit desktop и Chromium touch; база тематических проверок |
| fe11, reaudit, popup-qa | Frozen motion, адаптеры popup и lifecycle-регрессия |
| fos02, fos02-regression, popup-hover | Account, общий hover и production-режим |
| buttons, neutral-actions, plus-motion | Общие кнопки, поверхности и press |
| fos03, order-spacing | Отступы и статус заголовка |
| fos05, fos06, fos07, fos12 | Сохранение, операции позиции, календарь и макеты |
| comm-docs | Переписка, read/CRUD, PDF и media lifecycle |
| m7, next-scope | Сквозные разделы и регрессия исходного scope |
| orders, workspace | Отдельные cross-browser проверки заказов и рабочей области |
| material | Изолированная проверка Glass, команда npm run test:material |

Красная отметка «1» у fos06 на скриншоте означает диагностику редактора; по изображению её причину определить нельзя. Наличие отметки не доказывает, что файл лишний.

При ревизии все 23 конфига проверены через discovery (`--list`): каждый загружается и находит тесты; fos06 — 60 тестов. Это проверка конфигурации, без запуска браузеров или тестовых сценариев.

## Как поддерживать порядок

Обновлять существующий контракт вместе с изменением. Выполненный план удалять после переноса нужных правил и доказательств; историю оставлять в Git, без папки архивов и второго CURRENT. Не дублировать статусы поставки в checklist и справочнике источников. Новый документ создавать только для самостоятельной темы.

В ревизии 13.11 объединены парные документы №03/06/08–09/12, Account hover и Drawer QA; удалены завершённые планы и промежуточные отчёты. Frozen manifest, контрольные суммы и ссылки на нужные доказательства сохранены. Тяжёлые output/test-results/playwright-report локальные и ignored; их наличие проверяется перед использованием. Массовая очистка output в эту ревизию не входит: она смешала бы доказательства разных поставок.
